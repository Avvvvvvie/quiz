### Kinematik am Kreis

Geschwindigkeit $v = r/t$
Winkelgeschwindigkeit $omega = varphi/t = (2 pi) / T = 2 pi f$
Winkel als Funktion der Zeit $varphi(t) = omega * t = (2 pi)/T$
Frequenz $f = 1/T = omega / (2 pi)$
Höhe $= r * sin(varphi)$
Breite $= r * cos(varphi)$
Bahngeschwindigkeit $v(t) = omega * r * ( -sin(omega t); cos(omega t)) = omega * r$
Zentripetalbeschleunigung $a(t) = omega^2 * r * (-cos(omega t); -sin(omega t)) = v^2 / r$

Die Normal- oder Zentripetalbeschleunigung gibt den Betrag der Beschleunigung an, die ein Punkt auf einer Kreisbahn erfährt. Die Zentripetalbeschleunigung zeigt immer zur Drehachse und steht normal auf die Bahngeschwindigkeit.

### Dynamik
Newtonschen Gesetze
1. Trägheitsgesetz (Ohne äussere Kräfte bleibt der Impuls erhalten)
2. Aktionsprinzip ($vec F = m * vec a$)
3. Wechselwirkungsgesetz (Aktion = Reaktion)

### Kräfte

Starke und schwache Kernkraft

Gravitationskraft $F_g = G * (m_1 * m_2) / r_2 | G = 6.67 * 10^−11 m^3 / (kg s^2)$

Elektrostatische Kraft (Coulomb Kraft) $F_C = -1 / (4 pi epsi_0) (q_1 q_2) / r^2 | epsi_0 = 8.859 * 10^−12 C^2 / (N m^2)$

Federkraft $F = -k_("Feder") * Delta l$

Haftreibung (statisch) $F_(HR) = mu_H * F_N$

Gleitreibung (dynamisch) $F_(GR) = mu_G * F_N$ 

Laminare viskose Reibung $F = -k_("Dämpfer") * v$

Turbulente viskose Reibung $F_L = 1 / 2 * c_W * rho * A * v_(rel)^2$
